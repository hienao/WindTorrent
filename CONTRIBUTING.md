# Help improve WindTorrent

English and Chinese contributions are welcome. This repository hosts product documentation and feedback; application source code is private.

## Report a problem

Check the [FAQ](docs/faq.md) and search [existing issues](https://github.com/hienao/WindTorrent/issues) first. Use the bug report form and include the app version/edition, Android version, downloader type/version, network setup, reproduction steps, and expected versus actual behavior.

Public issues are visible to everyone. Remove connection credentials, private URLs, server addresses, personal task names, and identifying details from screenshots and logs. Do not attach backups. For sensitive reports, email [shiwentao666@gmail.com](mailto:shiwentao666@gmail.com).

## Suggest a feature

Use the feature request form. Describe what you want to accomplish, the downloader involved, and any current workaround. A concrete example helps more than a list of controls. Suggestions are welcome, but do not imply a delivery commitment.

## Improve documentation

Open a pull request for a correction, clearer instructions, or a translation. Keep English and Chinese versions aligned when practical, and use fictional addresses and credentials in examples. Only submit material you have the right to share. There is no application build step for documentation changes.

Keep privacy policy links pointing to the official website. App downloads are distributed through Google Play. Do not add application source code, binaries, real connection backups, or private development and release configuration to this repository.
