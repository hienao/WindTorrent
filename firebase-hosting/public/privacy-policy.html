WindTorrent

隐私政策

最后更新：2026年8月22日

WindTorrent（包名：com.hienao.windtorrent）是一款用于管理用户自行配置的 Aria2、qBittorrent 和 Transmission 服务的远程下载管理工具。本政策说明 WindTorrent 如何处理与本地配置、下载器连接、本地文件备份和使用分析有关的数据。

无需账号：WindTorrent 不提供登录或注册功能，不会收集您的姓名、邮箱、手机号或社交账号资料。

1. 保存在设备本地的数据

为了提供核心功能，WindTorrent 会在您的设备上保存：

  • 下载器配置：下载器类型、名称、服务器地址、端口及其他连接设置。
  • 下载器凭据：用户名、密码、RPC 密钥或访问令牌，用于连接您指定的下载器服务。
  • 导入回滚快照：导入 JSON 配置前保存的当前下载器配置，用于撤销上次导入。
  • 应用设置：语言、主题、更新提示和应用内评价提示记录等偏好。

这些数据用于在您的设备上提供相应功能。我们不会将下载器地址或下载器凭据上传到我们的服务器。

2. 下载器连接

当您添加、连接或管理下载任务时，WindTorrent 会直接向您配置的 Aria2、qBittorrent 或 Transmission 服务发送请求。您输入的下载 URL、磁力链接或选择的种子文件内容会发送给该下载器；应用也会展示下载器返回的任务、文件、速度、Tracker 和 Peer 等信息。请求目的地和传输安全性取决于您配置的服务器地址与协议。

WindTorrent 本身不提供、不托管且不存储任何下载内容。相关任务和文件保存在您的下载器服务器或设备上。

3. 本地 JSON 备份与恢复

导出配置时，WindTorrent 会通过系统文件选择器把 JSON 备份保存到您选择的位置。备份可能包含下载器地址、用户名、密码、RPC 密钥或访问令牌。导入时，应用会先校验文件格式，再将配置写入本地。

备份文件由您自行保存和管理。请将其存放在安全位置，避免向他人共享；删除应用不会自动删除已经导出到其他位置的备份文件。

4. Firebase Analytics

WindTorrent 使用 Firebase Analytics 了解应用功能的使用情况和稳定性。可能处理的信息包括：

  • 应用交互事件：应用启动、页面访问、下载器连接结果、任务操作结果、备份或恢复结果、设置变更和更新提示交互。
  • 应用与客户端环境：应用版本、构建号、平台、操作系统版本、语言地区、网络类型，以及 Android API level 和 Android 版本。
  • Firebase 自动收集的信息：Firebase SDK 可能依据设备和系统设置处理应用实例标识、设备信息、广告 ID、Android Privacy Sandbox 标识、IP 地址及由其推断的大致位置，以及诊断或归因相关信息。

WindTorrent 自行定义的分析事件不包含服务器地址、端口、路径、下载 URL、磁力链接、种子文件内容、下载任务名、文件名、邮箱、手机号、用户名、密码、密钥或令牌。我们不会使用分析数据识别您的下载内容。

WindTorrent 不展示广告，也不会使用广告 ID 投放个性化广告。Firebase Analytics 可能将相关标识用于分析、归因、反滥用或服务质量改进。

5. 第三方服务

WindTorrent 使用以下第三方服务：

  • Firebase Analytics：用于应用使用分析和稳定性改进。
  • Google Play 应用内评价：用于请求用户在 Google Play 中评价应用。
  • Google Play 应用内更新：用于检查并提示可用的应用更新。

Google 会根据其隐私政策处理相关信息：https://policies.google.com/privacy

6. 数据共享和出售

除向您指定的下载器以及上述为实现功能所必需的第三方服务传输数据外，我们不会出售、出租或向广告商提供您的个人信息、下载器配置、凭据或下载内容。

7. 数据保存与删除

  • 本地数据：您可以在应用中删除下载器配置。若要删除全部应用数据和导入回滚快照，可以通过系统设置清除 WindTorrent 的应用数据，或卸载应用。
  • 导出的备份文件：备份保存在您通过系统文件选择器指定的位置，需要由您通过系统文件管理器或对应存储服务自行删除。
  • 分析数据：Firebase Analytics 数据的保存和删除遵循 Google/Firebase 的政策与配置。

8. 数据安全

我们采取合理措施减少敏感信息进入分析系统。由于您连接的下载器和导出的 JSON 备份由您自行管理，请使用可信服务器、HTTPS、安全密码，并妥善保管备份文件。任何互联网传输或本地存储方式都无法保证绝对安全。

9. 儿童隐私

WindTorrent 不面向 13 岁以下儿童，也不会有意收集儿童个人信息。如果您认为我们无意中处理了儿童个人信息，请联系我们。

10. 政策更新

我们可能在功能或数据处理方式发生变化时更新本政策。更新后的版本会在本页面公布，并标明最后更新日期。
