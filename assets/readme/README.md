# Public presentation assets

- `icon.png`: WindTorrent's existing Android launcher icon.
- `overview.webp`, `downloaders.webp`, `tasks.webp`: resized and compressed versions of the official English [Google Play Pro listing](https://play.google.com/store/apps/details?id=com.hienao.windtorrent.pro) preview images, retrieved on 2026-10-19. They are store compositions of the app interface, not new captures of the latest version. Existing store previews may show older features. No UI content was altered.
- `social-preview.png`: the existing WindTorrent English feature graphic, fitted to a solid 1280 × 640 canvas for GitHub link sharing. Its downloader panel is a promotional illustration, not a live status display.

## Refreshing assets

Keep the real app interface as the visual proof. Use approved public store material or captures from a dedicated demo setup. Do not copy internal design mockups into the README as screenshots. For new captures, use fictional tasks and remove credentials, personal addresses, private trackers, and identifying information before publication.

Keep screenshots compressed, preserve their aspect ratio, and inspect the README at desktop and phone widths. The social preview must remain below 1 MB. Its repository setting is separate from the image file; upload it in GitHub **Settings → General → Social preview** when changing it.
